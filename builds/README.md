# Сборки

Отчёты сборок группы: `build-1.md` (встреча 5, модули в версии «правила») и `build-2.md`
(встреча 7, итоговые версии). Отчёт строит `run_build.py` руководителя на `main`: модуль, автор,
слой, прохождение проверки, число находок, время на статью, F1 по эталону. Состояние `main` на
момент сборки отмечено меткой `build-1` или `build-2`.
