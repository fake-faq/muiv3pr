# Ручные эталоны модулей

`gold/mNN.jsonl` — эталон модуля NN на 10 статьях общего тестового набора, по строке на объект.
Позиции не нужны: достаточно дословной цитаты начала фрагмента (30–80 символов). Цитату копируют
из текста base (`doc.text`), в PDF похожие символы бывают разными знаками Юникода.

```json
{"doc_id": "T0003", "cls": "moc:Theorem", "number": "2.1", "quote": "Теорема 2.1. Пусть X — рефлексивное"}
{"doc_id": "T0003", "pred": "moc:proves", "subj_quote": "Доказательство. По лемме 1.3", "obj_quote": "Теорема 2.1. Пусть X"}
{"doc_id": "T0003", "pred": "moc:hasDOI", "subj": "doc", "value": "10.1134/S0001434619010012"}
```

Качество считает `mathkg.evaluate.evaluate(инструмент, файл_эталона, base_dir, facts_dir)`.
