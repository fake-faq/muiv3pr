# Папки сдачи

У каждого студента своя папка `NN_фамилия` (номер варианта и фамилия латиницей, например
`07_ivanov`). В ней — блокноты этапов с выводами (`stage03.ipynb`) и папки этапов с отчётом и
небольшими результатами (`stage03/REPORT.md`, таблицы CSV, запросы `.rq`). Крупные результаты
(base, facts, графы `.nt`, векторы, индексы) остаются в личной папке на Google Drive; в репозиторий
они не кладутся.
