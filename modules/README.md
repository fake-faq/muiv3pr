# Студенческие модули

Каждый студент сдаёт сюда один файл — свой модуль: `mNN_<название>.py` (номер модуля = номер
варианта); модулю 4 можно положить рядом файл классификатора `m04_clf.joblib`. Начальная точка —
шаблон `mathkg/modules_template/mNN_template.py` или копия базовой версии из `mathkg/modules/`.

Правила:

1. Имя инструмента (`name`), зависимости (`requires`) и формат результата — как у базовой версии;
   их не меняют, от них зависят другие модули.
2. Чужие файлы не правятся. Ошибку в модуле соседа описывают в задаче (issue) репозитория с меткой
   модуля, например `m03`.
3. Среднее время модуля — не больше 2 с на статью; модели загружаются через `mathkg.models`
   (одна копия на сеанс), языковая модель — общая `Qwen/Qwen2.5-1.5B-Instruct`, ответы кэшируются
   в личной папке на Drive.
4. Перед сдачей модуль проходит `check_module` на тестовом наборе.

Модуль попадает сюда через запрос на слияние своей ветки в `main` (`ИНСТРУКЦИЯ_git.md`).
`pipeline.setup(student_modules=KG + '/modules')` подменяет базовые версии файлами из этой папки.
