# Инструменты запросов

С этапа 8 каждый студент сдаёт сюда файл `qNN_<название>.py` с инструментом запросов к графу
(`@query_tool`), например `proof_dependencies(statement_iri)` для модуля 7. Инструмент только
читает граф (SELECT/ASK, LIMIT). Файлы `q00_*.py` — общие инструменты руководителя.
Подключение: `pipeline.setup(..., query_tools=KG + '/query_tools')`.
